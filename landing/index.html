What Atlas does

From a long list of projects to a short list worth your time.

Explore and rank

Search, filter, browse categories and rankings, and surface hidden gems that the leaderboard buries.

For You

Recommendations from your interests and, optionally, a public GitHub profile. Nothing to sign in to.

Repository intelligence

Technology and architecture signals read from dependency manifests, file paths and READMEs, with the evidence shown next to each claim.

Compare 2–4 projects

Source metrics, architecture layers, technologies and evidence laid out side by side.

Research workspace

Study status, notes, questions, ideas and learning goals, saved in your browser with a snapshot of the repository evidence.

AI Researcher

Ask a question and get an answer grounded in retrieved Atlas records, citing projects by rank and name.

Evidence first

A keyword badge is not a code audit.

Atlas keeps the source facts from BharatCode separate from its own analysis, and every detected signal points back to the file, dependency or README line it came from. Previews of other people's repositories have likely credentials masked before they reach your browser. That masking is best effort, not a guarantee.

Strongest
Dependency manifests
Exact names from package.json, requirements.txt, pyproject.toml and more.
Medium
Repository file paths
Routes, Dockerfiles and CI configuration.
Weakest
README text
Used last, since anyone can write anything in a README.

Run Atlas yourself.

It is an open Next.js app over a static dataset. Add a GITHUB_TOKEN to raise GitHub rate limits and a model key to enable the AI Researcher.

Open the repository
# install and start
npm install
npm run dev
# run the test suite
npm test
